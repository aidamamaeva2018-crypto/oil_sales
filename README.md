## Источник:
https://www.kaggle.com/datasets/mahmoudshaheen1134/oil-sales-dataset?resource=download
## Что сделано:
1. Обработка данных: поиск пустых ячеек(0), дубликатов(0), неконсистентные форматы(значок $ в диапазоне стоимости). Также было найдено несоответсвие с документацией(данные за 2022-2023гг, но треть данных за 2024г; скорее всего забыли обновить).
2. Поиск выбросов через межквартильный размах(147 аномалий); их классификация и сравнение с медианной стоимостью. Таким образом было выявлено 22 значащих выброса, однако при прямом исследовании не было обнаружено проблем с данными(больше похоже на оптовые закупки).
3. Моделирование: 1. Линейная регрессия(baseline) дает отрицательную метрику R^2 
                  2. методом XGBoost достигается R^2 = 0.98 и RMSE = 102.51(показывает небольшую потерю в деньгах ~102$)
